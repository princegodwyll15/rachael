# For Racheal — from Prince Godwyll

A complete standalone website. No ChatGPT, backend, npm dependencies, or build step required.

## Preview
Open index.html in your browser.

## Publish
Upload index.html to any static website host. It must be at the root of your published folder. If the host asks for a build command, leave it empty; choose the folder containing index.html as the publish directory.

Use HTTPS for clipboard support, then send your published URL to Racheal.

## Customize
All text, CSS and JavaScript are in index.html. Open it in VS Code to edit the letter, names, colors or reply messages.

## Replies
Her answer appears on the page. It is not automatically sent or stored. She can use Copy my reply and paste it into a message to Prince.

The original hosted site remains unchanged.
